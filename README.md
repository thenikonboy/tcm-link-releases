### 💡 บันทึกการปรับปรุง (Changelog v2.5.0)
- บันทึกฝังเข็ม OPD Case & เคสฟื้นฟูของ รพ. แยกอิสระ
- รองรับการคีย์รับเคสใหม่โดยโรงพยาบาลเองโดยตรง พร้อมอนุมัติทันที
- สรุปรายงานพัฒนาการ Barthel Index แยกรายเดือน (12 เดือน), รายไตรมาส (Q1-Q4) และรายปีงบประมาณ
- มาตรฐานคะแนน Barthel Index 0-20 คะแนนในทุกรายงาน กราฟพัฒนาการ และแบบฟอร์มเวชระเบียน
- พิมพ์รายงานเวชระเบียนผู้ป่วยฟื้นฟู IMC (แบบฟอร์ม TCM-IMC-01) ขนาดมาตรฐาน A4
- ระบบตรวจเช็กและดาวน์โหลดอัปเดตผ่าน GitHub Releases อัตโนมัติ ปลอดภัย ข้อมูลคนไข้ไม่สูญหาย
